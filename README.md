Student management system

A Flask-based web application for managing students, groups, and courses with PostgreSQL. Features CRUD operations, data generation, and REST API endpoints.

## Technologies used

| Component                | Description                                                              |
|--------------------------|--------------------------------------------------------------------------|
| **Python 3**             | Main programming language                                                |
| **Flask**                | A lightweight web framework for routing, templating and server startup   |
| **Flask-RESTful**        | REST API extension for Flask                                             |
| **SQLAlchemy**           | ORM for PostgreSQL database interactions                                 |
| **PostgreSQL**           | Relational database for data storage                                     |
| **Faker**                | Test data generation                                                     |
| **pytest**               | Testing framework                                                        |

## Web application features

✅ CRUD Operations – Create, read, update, and delete students, groups, and courses
✅ REST API – JSON-based endpoints for integration
✅ Data Generation – Random student/group/course generation with Faker
✅ PostgreSQL Backend – Reliable and scalable database
✅ Unit Tests – Test coverage with pytest
